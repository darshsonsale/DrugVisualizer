 Drug Path Visualiser
 Professional MVP Implementation Roadmap
 
Project Overview
Drug Path Visualiser is a mobile-friendly educational web application that helps general users understand what happens to an
orally taken drug through an interactive 3D abstract pathway. The MVP focuses on Ibuprofen, with Before Food / After Food
as the only dynamic pathway condition.
Project Goals
 Build a clear educational visualization of the Ibuprofen pathway.
 Keep scientific content separate from 3D presentation logic.
 Create an architecture that can support additional drugs later.
 Provide anonymous access with optional Google sign-in.
 Implement secure backend validation and authorization.
 Build a maintainable modular-monolith architecture.
 Establish a strong testing and integration process.
Technology Stack
 Frontend: React + TypeScript
 3D: Three.js + React Three Fiber
 Backend: Node.js + TypeScript
 Architecture: Modular Monolith
 Database: PostgreSQL
 API: REST over HTTPS
 Authentication: Google OAuth/OIDC
 Testing: Unit, API, integration, security and E2E testing
 Version Control: Git
Architecture
Browser → React + TypeScript + Three.js/R3F → REST/HTTPS → Node.js + TypeScript modular monolith → PostgreSQL.
Backend modules: Authentication, Drug & Pathway, Content, Quiz, Progress and Administration.
Total Tasks: 30
Estimated Duration: Approximately 6–8 weeks for a 3-person team.
Difficulty: Intermediate → Advanced
